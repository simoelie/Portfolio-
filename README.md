# Elie Simo — Business Analysis, BI & Data Analytics portfolio

A static, responsive portfolio for GitHub Pages at https://simoelie.github.io/Portfolio-/.

## Project overview

The site presents four case studies spanning BI reporting, business process analysis, workforce analytics and econometric research. `index.html` is the landing page; `case-study.html` contains detailed project notes. `style.css` and `script.js` provide responsive presentation, project filtering, mobile navigation and bilingual core copy.

## Business problem and objectives

Recruiters need to understand both the work and the reasoning behind it. The portfolio exposes business questions, inputs, methods, recommendations and evidence limits rather than listing tools alone.

## Dataset and confidentiality

The Power BI report is externally published. The academic research includes the thesis PDF (`memoire-elie-simo.pdf`) provided by the author. The healthcare cases are anonymized and contain no employer records. The business process requirements and flow are illustrative proposed artifacts.

## Methodology and tools

The case pages explain KPI framing, requirements, process mapping, UAT, trend analysis, long-difference panel estimation and a climate-based shift-share instrumental variable. Technologies cited include Power BI, Stata, SQL, Python, DAX and Power Query where supported by the portfolio and CV; no unpublished implementation code is represented as available.

## Key insights and recommendations

A useful analytics product begins with a decision question, stable definitions and a validation plan. The absence cases emphasize early visibility, ownership and testable handoffs. Research interpretation separates associations from causal claims.

## Screenshots and exploration

Open the public site or `index.html` locally. The Power BI report may restrict embedding in some browsers; use the Live Dashboard link if the iframe cannot render. There are no public source datasets, SQL scripts, Python notebooks or DAX expressions in this repository. Add those folders only when publishable artifacts exist.

## Run locally

No build is needed. Open `index.html`, or run `python3 -m http.server 8000` and visit `http://localhost:8000/`.

## Assets

`portrait-elie-simo.jpeg` is the user-supplied portrait. `certification-microsoft-pl300-elie-simo.jpeg` is the user-supplied Microsoft Power BI certification image, linked at full size from the education section. `tableau-de-bord-arriere-plan.jpeg` and `CV_Elie_Simo.pdf` are retained from the existing repository.
